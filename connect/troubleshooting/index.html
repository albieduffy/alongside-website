Troubleshooting¶

Trouble connecting?¶

  • Check the address is pasted exactly, including /mcp at the end.
  • Make sure Alongside is switched on in the chat you're using. In ChatGPT, type @ and choose Alongside.
  • Try starting a new chat.

Check it's working¶

Start a new chat (in ChatGPT, type @ and choose Alongside first) and ask: "What can Alongside help with?" It should mention crisis support, wellbeing check-ins, explainers, exercises and finding a professional.

Still stuck?¶

Email hello@alongside.london.
